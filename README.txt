Polycraft Studio — iPhone PWA Bundle
====================================
1. Upload this entire ZIP (or its contents) to Netlify Drop (https://app.netlify.com/drop)
   or a GitHub Pages repository.
2. Open the live https:// link in Safari on your iPhone.
3. Tap Share -> Add to Home Screen -> make sure "Open as Web App" is ON -> tap Add.
4. Open Polycraft Studio once while online so the Service Worker caches assets for offline use.
